# Mohan Sharma Portfolio

Phase 1 foundation for a React + TypeScript + Vite portfolio using Styled Components, React Router, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run typecheck
npm run build
```
